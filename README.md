# Olympic_Medal_Dashboard

## Overview 
This project was made using Power BI, using the dataset for the number of medals each country
won during the 2020 Summer Olympic Games in Tokyo. The dataset was downloaded from
Kaggle and contains the number of Gold, Silver, and Bronze medals each country won, and a
country ranking based on the number of medals a country won.
The key fields used were:
● Country
● Gold Medals
● Silver Medals
● Bronze Medals
● Total Medals
● Rank by Total Medals

## Purpose and Intended Audience 
The purpose of the dashboard is to provide the user with a clear understanding of how well a
particular country performed at the 2020 Summer Olympics. The dashboard is designed to help
users quickly identify the top-performing countries and compare the medal count for the different
countries.
The intended audience is:
● Sports analysts
● General users interested in the Olympics
● Students studying data science
The dashboard is made to be simple and easy to use, so users can find information about the
summer Olympics without needing knowledge about how to use Power BI.
